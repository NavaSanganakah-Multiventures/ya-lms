# YA-LMS (Adityanveshan LMS) - परियोजना अवलोकन

## परिचय
YA-LMS एक आधुनिक लर्निंग मैनेजमेंट सिस्टम (LMS) है जो योग, आयुर्वेद और आध्यात्मिक शिक्षा के लिए बनाया गया है। यह **Yagya Ashram** के लिए डिज़ाइन किया गया एक पूर्ण-स्टैक वेब एप्लिकेशन है।

## तकनीकी स्टैक (Tech Stack)

| घटक | तकनीक |
|------|--------|
| **फ्रंटएंड फ्रेमवर्क** | Next.js 15 (App Router), React 19 |
| **स्टाइलिंग** | Tailwind CSS 4, Framer Motion |
| **बैकएंड** | Cloudflare Workers (Node.js compat) |
| **डेटाबेस** | Cloudflare D1 (SQLite-आधारित) |
| **स्टोरेज** | Cloudflare R2 (फ़ाइलें, वीडियो) |
| **सीक्रेट्स/कॉन्फ़िग** | Cloudflare KV |
| **प्रमाणीकरण** | OTP-आधारित (पासवर्डलेस), JWT (HMAC-SHA256) |
| **भुगतान** | Razorpay |
| **एआई** | Google Gemini (Cloudflare AI Gateway) |
| **रीयल-टाइम** | Cloudflare RealtimeKit (WebRTC) |
| **ईमेल** | Cloudflare Email Workers |
| **पुश नोटिफिकेशन** | Firebase Cloud Messaging (FCM) + Web Push (VAPID) |
| **मोबाइल** | Flutter (Android + Linux) |
| **ट्रांसक्रिप्शन** | OpenAI Whisper (Cloudflare AI) |
| **सीआई/सीडी** | GitHub Actions + Wrangler |

## मुख्य विशेषताएं (Key Features)

1. **ऑनलाइन कोर्सेज** - वीडियो, पीडीएफ, लेख, रिकॉर्डिंग के साथ संरचित पाठ्यक्रम
2. **लाइव कक्षाएं** - WebRTC-आधारित रीयल-टाइम इंटरैक्टिव कक्षाएं
3. **परीक्षाएं** - प्रॉक्टरिंग के साथ ऑनलाइन परीक्षा प्रणाली
4. **प्रमाणपत्र** - कोर्स पूरा होने पर स्वचालित पीडीएफ प्रमाणपत्र
5. **क्रेडिट सिस्टम** - एआई सेवाओं के लिए क्रेडिट-आधारित अर्थव्यवस्था
6. **एआई ट्यूटर** - जेमिनी-संचालित एआई शिक्षण सहायक
7. **गेमिफिकेशन** - बैज, ट्रॉफी, एक्सपी सिस्टम
8. **पुश नोटिफिकेशन** - FCM + वेब पुश के माध्यम से सूचनाएं
9. **बुक्स** - डिजिटल पुस्तकें पढ़ने की सुविधा
10. **फॉर्म** - डायनामिक फॉर्म टेम्पलेट और सबमिशन
11. **बैचेज** - बैच-आधारित प्रबंधन और शेड्यूलिंग
12. **लीव मैनेजमेंट** - छात्र छुट्टी प्रबंधन

## प्रोजेक्ट संरचना

```
ya-lms/
├── app/              → Next.js फ्रंटएंड पेजेस

├── lib/              → उपयोगिताएं (cn, time, pdf, firebase)
├── src/              → Cloudflare Worker बैकएंड
│   ├── index.ts      → मुख्य वर्कर (~21K लाइनें)
│   ├── routes/auth.ts→ Zod स्कीमा
│   └── workflows.ts  → ट्रांसक्रिप्शन वर्कफ़्लो
├── public/           → स्थैतिक संसाधन
├── flutter/          → Flutter मोबाइल ऐप्स
├── translations/     → i18n फ़ाइलें (EN/HI)
├── tests/            → जेस्ट टेस्ट फ़ाइलें
├── schema.sql        → डेटाबेस स्कीमा

```

## पर्यावरण और विन्यास

### मुख्य फ़ाइलें:
- `wrangler.jsonc` - Cloudflare वर्कर विन्यास (सभी बाइंडिंग्स)
- `next.config.ts` - Next.js विन्यास (वर्कर को रिवाइट्स)
- `.env.example` - आवश्यक पर्यावरण चर
- `package.json` - निर्भरताएं और स्क्रिप्ट्स
- `tsconfig.json` - TypeScript विन्यास

### डेटाबेस:
Cloudflare D1 का उपयोग करता है। मुख्य स्कीमा `schema.sql` में परिभाषित है जिसमें 30+ टेबल हैं। `db-migrate.ts` ऑटो-माइग्रेशन का काम करता है।
