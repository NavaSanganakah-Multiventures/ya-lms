# फॉर्म प्रबंधन (Form Management)

## अवलोकन
YA-LMS में एक डायनामिक फॉर्म प्रणाली है जो एडमिन को कस्टम फॉर्म टेम्पलेट बनाने और छात्रों को उन्हें भरने की अनुमति देती है।

---

## 1. डेटाबेस टेबल

### FormTemplates
| फ़ील्ड | विवरण |
|--------|--------|
| `id` | अद्वितीय आईडी |
| `title` | फॉर्म का शीर्षक |
| `description` | विवरण |
| `fields` | फ़ील्ड परिभाषाएं (JSON) |
| `status` | `draft` / `published` |
| `created_at` | निर्माण तिथि |

### FormResponses
| फ़ील्ड | विवरण |
|--------|--------|
| `id` | अद्वितीय आईडी |
| `form_template_id` | टेम्पलेट आईडी |
| `user_id` | उपयोगकर्ता आईडी |
| `responses` | उत्तर (JSON) |
| `submitted_at` | सबमिशन तिथि |

---

## 2. फ्रंटएंड पेजेस

### फॉर्म सबमिशन
- `app/form/page.tsx` - सार्वजनिक फॉर्म रेंडरर
- `app/dashboard/forms/page.tsx` - डैशबोर्ड में असाइन किए गए फॉर्म

### फॉर्म बिल्डर
- `app/admin/forms/page.tsx` - एडमिन फॉर्म टेम्पलेट बिल्डर

### फॉर्म उत्तर
- `app/admin/form-responses/page.tsx` - सबमिट किए गए फॉर्म देखें

---

## 3. फॉर्म फ़ील्ड प्रकार

फॉर्म टेम्पलेट विभिन्न फ़ील्ड प्रकारों का समर्थन करता है (JSON में परिभाषित):
- टेक्स्ट इनपुट
- नंबर इनपुट
- ड्रॉपडाउन/सेलेक्ट
- चेकबॉक्स
- रेडियो बटन
- टेक्स्टएरिया
- फ़ाइल अपलोड
- दिनांक चयनकर्ता

---

## 4. API एंडपॉइंट्स

| एंडपॉइंट | विधि | विवरण |
|-----------|------|--------|
| `/api/forms/:id` | GET | फॉर्म टेम्पलेट प्राप्त करें |
| `/api/forms/:id` | POST | फॉर्म सबमिट करें |
| `/api/admin/forms` | GET/POST | एडमिन फॉर्म CRUD |
| `/api/admin/form-responses` | GET | फॉर्म उत्तर देखें |

---

## 5. फॉर्म सर्वेक्षण उपयोग

फॉर्म का उपयोग विभिन्न उद्देश्यों के लिए किया जा सकता है:
- छात्र सर्वेक्षण
- प्रतिक्रिया संग्रह
- आवेदन पत्र
- पंजीकरण फॉर्म
- कस्टम डेटा संग्रह

---

यह दस्तावेज़ फॉर्म प्रबंधन प्रणाली का विवरण प्रदान करता है।
