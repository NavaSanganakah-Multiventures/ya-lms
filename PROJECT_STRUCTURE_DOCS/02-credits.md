# क्रेडिट सिस्टम (Credit System)

## अवलोकन
YA-LMS में एक पूर्ण क्रेडिट-आधारित अर्थव्यवस्था है जो एआई सेवाओं, कोर्सेज और अन्य सुविधाओं तक पहुंच प्रदान करती है।

---

## 1. क्रेडिट वॉलेट (Credit Wallets)

### डेटाबेस टेबल: `CreditWallets`

| फ़ील्ड | विवरण |
|--------|--------|
| `id` | अद्वितीय आईडी |
| `user_id` | उपयोगकर्ता आईडी |
| `balance` | वर्तमान शेष (क्रेडिट में) |
| `total_earned` | कुल अर्जित क्रेडिट |
| `total_spent` | कुल खर्च किए गए क्रेडिट |
| `created_at` / `updated_at` | निर्माण/अद्यतन तिथि |

### डेटाबेस टेबल: `CreditTransactions`

| फ़ील्ड | विवरण |
|--------|--------|
| `id` | अद्वितीय आईडी |
| `wallet_id` | वॉलेट आईडी |
| `amount` | राशि (धनात्मक = जमा, ऋणात्मक = निकासी) |
| `type` | `purchase` / `usage` / `admin_credit` / `refund` |
| `description` | लेन-देन का विवरण |
| `reference_id` | संदर्भ आईडी (कोर्स, एआई कॉल आदि) |
| `created_at` | तिथि |

---

## 2. क्रेडिट अर्थव्यवस्था

### मूल्य निर्धारण:
- **डिफ़ॉल्ट दर**: 10 क्रेडिट = ₹1
- **फ़ीचर्ड पैक**: ₹101 = 1000 क्रेडिट्स (लगभग 10% बोनस)
- **एआई कॉल लागत**: 2 क्रेडिट प्रति एआई क्वेरी (डिफ़ॉल्ट)

### क्रेडिट स्रोत:
1. **खरीद** - `BuyCreditsModal` के माध्यम से Razorpay भुगतान
2. **एडमिन क्रेडिट** - एडमिन किसी भी उपयोगकर्ता को क्रेडिट दे सकता है
3. **कोर्स एनरोलमेंट** - कुछ कोर्सेज क्रेडिट से खरीदे जा सकते हैं
4. **बैच एनरोलमेंट** - बैच में शामिल होने पर क्रेडिट काटे जाते हैं

### क्रेडिट उपयोग:
1. **एआई ट्यूटर** - पाठ स्तर पर एआई सहायता
2. **एआई असिस्टेंट** - डैशबोर्ड/एडमिन एआई चैट
3. **कंटेंट जनरेशन** - कोर्स/फॉर्म सामग्री एआई जनरेशन
4. **कोर्स खरीद** - क्रेडिट से कोर्स एनरोलमेंट

---

## 3. फ्रंटएंड कंपोनेंट्स

### BuyCreditsModal (`components/BuyCreditsModal.tsx`)
- क्रेडिट खरीदने के लिए मोडल
- Razorpay ऑर्डर निर्माण
- पूर्वनिर्धारित पैक विकल्प

### CreditsContext (`contexts/CreditsContext.tsx`)
- `GET /api/credits/balance` से बैलेंस प्राप्त करता है
- पूरे ऐप में क्रेडिट बैलेंस उपलब्ध कराता है
- `refreshCredits()` फ़ंक्शन
- डैशबोर्ड लेआउट में प्रदर्शित

### useCreditWallet (`hooks/useCreditWallet.ts`)
- `useCreditWallet()` - वॉलेट विवरण प्राप्त करता है
- `useAddCredits()` / `useIssueCredits()` - एडमिन क्रेडिट म्यूटेशन

---

## 4. एडमिन पेज

### `app/admin/credits/page.tsx`
- सभी उपयोगकर्ताओं के वॉलेट देखें
- क्रेडिट जारी करें/जोड़ें
- लेन-देन इतिहास देखें

### API:
- `POST /api/admin/credits` - एडमिन क्रेडिट प्रबंधन (OTP-सुरक्षित)
- `GET /api/credits/balance` - बैलेंस चेक

---

## 5. बैकएंड हैंडलिंग (`src/index.ts`)

### मुख्य फ़ंक्शन:
- `calculateAICreditsForPurchase()` - खरीद के लिए क्रेडिट गणना
- `getAICreditDeductionPerRequest()` - प्रति-अनुरोध क्रेडिट लागत
- `addCreditsToWallet()` - वॉलेट में क्रेडिट जोड़ना
- `handleAdminGiveCredits()` - OTP-सुरक्षित एडमिन क्रेडिट

## 6. क्रेडिट रूपांतरण दरें

| मद | क्रेडिट लागत |
|-----|--------------|
| 1 AI क्वेरी | 2 क्रेडिट्स (डिफ़ॉल्ट) |
| ₹1 मूल्य | 10 क्रेडिट्स |
| ₹101 पैक | 1000 क्रेडिट्स |
| बैच एनरोलमेंट | `batch.credit_cost` के अनुसार |
| कोर्स खरीद | `course.price_rupees × 10` क्रेडिट्स |
