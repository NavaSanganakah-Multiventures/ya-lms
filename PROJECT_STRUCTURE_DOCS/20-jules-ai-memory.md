# जूल्स एआई मेमोरी (Jules AI Memory)

## अवलोकन
YA-LMS में **Jules AI** नामक एक ऑटोमेटेड AI एजेंट है जो अपनी सीख को मेमोरी फ़ाइलों में संग्रहीत करता है। ये फ़ाइलें `.Jules/` और `.jules/` डायरेक्टरी में स्थित हैं और इनमें UX, सुरक्षा, और प्रदर्शन से संबंधित सीख शामिल हैं।

---

## 1. UX पैलेट (Palette)

### फ़ाइल: `.Jules/palette.md`

यह फ़ाइल UX और एक्सेसिबिलिटी पैटर्न को ट्रैक करती है:

**सीखे गए पाठ:**

1. **आइकन-ओनली बटन एक्सेसिबिलिटी**
   - आइकन वाले बटनों में `aria-label` जोड़ना अनिवार्य
   - स्क्रीन रीडर उपयोगकर्ताओं के लिए `title` एट्रिब्यूट भी जोड़ें
   - उदाहरण: `EditButton`, `DeleteButton`, `CloseButton`

2. **साइड इफेक्ट स्कोपिंग**
   - कंपोनेंट अपडेट करते समय साइड इफेक्ट को सीमित रखें
   - अप्रत्याशित व्यवहार से बचने के लिए स्कोपिंग महत्वपूर्ण

3. **कीबोर्ड एक्सेसिबिलिटी**
   - टेबल एक्शन (`opacity-0 on hover`) कीबोर्ड से एक्सेसिबल नहीं थे
   - `opacity-0` के बजाय `opacity-0 sm:group-hover:opacity-100` का उपयोग करें
   - `focus-within` भी जोड़ें ताकि कीबोर्ड नेविगेशन काम करे

## 2. सुरक्षा सेंटिनल (Security Sentinel)

### फ़ाइल: `.jules/sentinel.md`

यह फ़ाइल सुरक्षा कमजोरियों और उनके समाधान को ट्रैक करती है:

**पाई गई समस्याएं और समाधान:**

1. **असुरक्षित रैंडमनेस (Insecure Randomness)**
   - **समस्या:** OTP जनरेशन के लिए `Math.random()` का उपयोग
   - **जोखिम:** `Math.random()` क्रिप्टोग्राफिक रूप से सुरक्षित नहीं है
   - **समाधान:** `crypto.getRandomValues()` का उपयोग करें
   - **फ़ंक्शन:** `generateSecureOTP()` in `src/index.ts`

2. **असुरक्षित React DOM इंजेक्शन**
   - **समस्या:** `dangerouslySetInnerHTML` का उपयोग
   - **जोखिम:** XSS (Cross-Site Scripting) हमले
   - **समाधान:** `isomorphic-dompurify` लाइब्रेरी का उपयोग करें
   - HTML को रेंडर करने से पहले सैनिटाइज़ करें

3. **असुरक्षित क्रॉस-ओरिजिन postMessage**
   - **समस्या:** `targetOrigin: '*'` के साथ `postMessage`
   - **जोखिम:** किसी भी ओरिजिन से संदेश स्वीकार करना
   - **समाधान:** `targetOrigin: window.location.origin` पर सेट करें

## 3. प्रदर्शन बोल्ट (Performance Bolt)

### फ़ाइल: `.jules/bolt.md`

यह फ़ाइल प्रदर्शन अनुकूलन को ट्रैक करती है:

**पाई गई समस्याएं और समाधान:**

1. **Next.js डायनामिक रेंडरिंग**
   - **समस्या:** एरे फ़िल्टरिंग में डायनामिक रेंडरिंग (हर बार नई ऐरे बनाना)
   - **समाधान:** `useMemo` में फ़िल्टरिंग एक्सट्रैक्ट करें
   - सिंगल-पास स्टैट्स कैलकुलेशन (कई `.filter()` कॉल के बजाय एक लूप)

## 4. जूल्स ऑटोमेशन इंटीग्रेशन

जूल्स एआई इन मेमोरी फ़ाइलों के अलावा, `src/index.ts` में जूल्स ऑटोमेशन के लिए API हैंडलर हैं:

- `handleAdminErrorSessions()` - एरर सेशन CRUD
- `runErrorAutomation()` - स्वचालित एरर फिक्स
- `sendPromptToJules()` - जूल्स API को प्रॉम्प्ट भेजना
- `syncJulesJobActivities()` - जूल्स जॉब एक्टिविटी सिंक

### API एंडपॉइंट्स:
- `GET /api/admin/error-sessions` - एरर सेशन सूची
- `POST /api/admin/error-sessions/:id/generate-prompt` - प्रॉम्प्ट जनरेशन
- `POST /api/admin/error-sessions/:id/send-to-jules` - जूल्स को भेजें
- `POST /api/admin/error-sessions/:id/ignore` - अनदेखा करें
- `POST /api/admin/error-sessions/:id/resolve` - हल किया गया

यह दस्तावेज़ जूल्स एआई मेमोरी फ़ाइलों और ऑटोमेशन सिस्टम का विवरण प्रदान करता है।
