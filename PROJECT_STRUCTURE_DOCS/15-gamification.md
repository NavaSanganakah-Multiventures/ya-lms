# गेमिफिकेशन (Gamification)

## अवलोकन
YA-LMS में एक पूर्ण गेमिफिकेशन प्रणाली है जो छात्रों को प्रेरित करने के लिए **बैज, ट्रॉफी, XP, और स्तर** का उपयोग करती है।

---

## 1. डेटाबेस टेबल

### Gamification
| फ़ील्ड | विवरण |
|--------|--------|
| `id` | अद्वितीय आईडी |
| `course_id` | कोर्स आईडी (वैकल्पिक) |
| `xp_per_lesson` | प्रति पाठ XP |
| `xp_per_exam` | प्रति परीक्षा XP |
| `level_thresholds` | स्तर सीमाएं (JSON) |
| `enabled` | सक्रिय/निष्क्रिय |

### Badges
| फ़ील्ड | विवरण |
|--------|--------|
| `id` | अद्वितीय आईडी |
| `name` | बैज का नाम |
| `description` | विवरण |
| `icon_url` | बैज छवि |
| `requirement` | आवश्यकता (पाठ/परीक्षा/दिन) |
| `type` | `course` / `streak` / `achievement` |

### UserTrophies
| फ़ील्ड | विवरण |
|--------|--------|
| `id` | अद्वितीय आईडी |
| `user_id` | उपयोगकर्ता आईडी |
| `badge_id` | बैज आईडी |
| `awarded_at` | प्रदान करने की तिथि |

---

## 2. उपलब्धियां (Trophies)

### `app/dashboard/trophies/page.tsx`
- उपयोगकर्ता के सभी बैज और ट्रॉफी प्रदर्शित करता है
- GET `/api/user/badges` से डेटा प्राप्त करता है

### `app/admin/trophies/page.tsx`
- बैज/ट्रॉफी CRUD
- नए बैज बनाएं/संपादित करें/हटाएं

---

## 3. XP और स्तर (XP & Levels)

### XP अर्जन:
| कार्य | XP |
|-------|-----|
| पाठ पूरा करना | `gamification.xp_per_lesson` (डिफ़ॉल्ट) |
| परीक्षा उत्तीर्ण | `gamification.xp_per_exam` (डिफ़ॉल्ट) |
| लगातार सीखना | स्ट्रीक बोनस |

### स्तर प्रणाली:
- `level_thresholds` JSON में परिभाषित
- प्रत्येक स्तर पर नई उपलब्धियां अनलॉक

---

## 4. एडमिन सेटिंग्स

### `app/admin/gamification/page.tsx`
- XP प्रति पाठ/परीक्षा सेटिंग
- स्तर सीमाएं कॉन्फ़िगरेशन
- गेमिफिकेशन सक्षम/अक्षम

### API:
- `POST /api/admin/gamification` - गेमिफिकेशन सेटिंग्स अपडेट करें

---

## 5. लगातार सीखना (Learning Streaks)

डैशबोर्ड एनालिटिक्स में ट्रैक किया जाता है:
- `app/dashboard/analytics/page.tsx` - सीखने की आदतें
- `GET /api/user/analytics` - विश्लेषण डेटा

---

## 6. बैज प्रकार

| प्रकार | विवरण |
|--------|--------|
| `course` | कोर्स पूरा करने पर |
| `streak` | लगातार सीखने के लिए |
| `achievement` | विशेष उपलब्धियों के लिए |
| `exam` | परीक्षा में उच्च अंकों के लिए |

---

यह दस्तावेज़ गेमिफिकेशन प्रणाली का विस्तृत विवरण प्रदान करता है।
