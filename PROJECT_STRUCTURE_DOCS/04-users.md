# उपयोगकर्ता प्रबंधन (User Management)

## अवलोकन
YA-LMS में तीन भूमिकाओं (roles) के साथ एक पूर्ण उपयोगकर्ता प्रबंधन प्रणाली है: **छात्र (Student)**, **शिक्षक (Teacher)**, और **एडमिन (Admin)**।

---

## 1. डेटाबेस टेबल: `Users`

| फ़ील्ड | विवरण |
|--------|--------|
| `id` | अद्वितीय उपयोगकर्ता आईडी |
| `student_id` | छात्र आईडी (प्रारूप: `YA{YY}{COUNTRY}{MONTH}{STATE}{SEQ4}{INITIAL}`) |
| `name` | पूरा नाम |
| `email` | ईमेल (अद्वितीय) |
| `phone` | फ़ोन नंबर |
| `role` | `student` / `teacher` / `admin` |
| `profile_picture_url` | प्रोफ़ाइल चित्र (R2 URL) |
| `batch_id` | बैच असाइनमेंट |
| `whatsapp_number` | व्हाट्सएप नंबर |
| `family_details` | परिवार विवरण (JSON) |
| `address` | पता (JSON) |
| `education` | शिक्षा विवरण (JSON) |
| `timezone` | समय क्षेत्र |
| `language` | पसंदीदा भाषा (en/hi) |
| `status` | `active` / `inactive` |
| `currency` | मुद्रा प्राथमिकता |
| `created_at` / `updated_at` | निर्माण/अद्यतन तिथि |

---

## 2. छात्र आईडी प्रारूप

स्वचालित रूप से जनरेट की जाती है:
```
YA{YY}{COUNTRY}{MONTH}{STATE}{SEQ4}{INITIAL}

YA 25 IN 06 UP 0001 J
│  │  │  │   │   │   └─ आद्याक्षर
│  │  │  │   │   └───── अनुक्रम संख्या (4 अंक)
│  │  │  │   └───────── राज्य कोड
│  │  │  └───────────── माह (01-12)
│  │  └──────────────── देश कोड
│  └─────────────────── वर्ष (25 = 2025)
└────────────────────── स्थिर उपसर्ग
```

---

## 3. उपयोगकर्ता कार्य

### प्रोफ़ाइल प्रबंधन:
- **देखें**: `app/dashboard/profile/page.tsx` → `GET /api/auth/me`
- **संपादित करें**: `app/dashboard/settings/page.tsx` → `PUT /api/user/profile`
- **सेटिंग्स**: मुद्रा, भाषा, सूचनाएं, डिवाइस

### एडमिन उपयोगकर्ता प्रबंधन:
- **सूची**: `app/admin/users/page.tsx` → `GET /api/admin/users`
- **संपादित करें**: `app/admin/users/page.tsx` → `PUT /api/admin/users/:id`
- **हटाएं**: OTP-सुरक्षित, 20+ टेबलों से कैस्केडिंग सफाई
- **क्रेडिट टॉप-अप**: एडमिन क्रेडिट जोड़ सकता है
- **बैच असाइनमेंट**: छात्रों को बैच में असाइन करें

---

## 4. उपयोगकर्ता भूमिकाएं और अनुमतियां

| भूमिका | पहुंच |
|--------|--------|
| **छात्र** | डैशबोर्ड, कोर्सेज, परीक्षाएं, प्रोफ़ाइल, लीव, फॉर्म |
| **शिक्षक** | एडमिन तक सीमित पहुंच (अपने कोर्सेज, छात्र) |
| **एडमिन** | पूर्ण पहुंच (सभी एडमिन पेजेस, सेटिंग्स, उपयोगकर्ता) |

---

## 5. संबंधित फ़ाइलें

### फ्रंटएंड:
- `app/dashboard/settings/page.tsx` - उपयोगकर्ता सेटिंग्स
- `app/admin/users/page.tsx` - एडमिन उपयोगकर्ता CRUD

### बैकएंड (`src/index.ts`):
- `handleSendOTP()` - OTP भेजना
- `handleVerifyOTP()` - OTP सत्यापन + JWT जारी
- `handleRegister()` - नया उपयोगकर्ता पंजीकरण
- `handleAdminUsers()` - एडमिन उपयोगकर्ता CRUD
- `generateStudentId()` - छात्र आईडी जनरेशन
