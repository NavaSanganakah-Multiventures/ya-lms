# प्रमाणीकरण प्रणाली (Authentication System)

## अवलोकन
YA-LMS एक पूर्ण **पासवर्डलेस OTP-आधारित प्रमाणीकरण** प्रणाली का उपयोग करता है। इसमें कोई पासवर्ड नहीं है - केवल ईमेल के माध्यम से OTP भेजा जाता है।

---

## 1. प्रमाणीकरण प्रवाह (Auth Flow)

### लॉगिन प्रक्रिया:
```
1. उपयोगकर्ता ईमेल दर्ज करता है
2. POST /api/auth/send-otp → OTP ईमेल पर भेजा जाता है
3. उपयोगकर्ता OTP दर्ज करता है
4. POST /api/auth/verify-otp → JWT कुकी सेट होती है
5. डैशबोर्ड पर रीडायरेक्ट
```

### रजिस्ट्रेशन प्रक्रिया:
```
1. उपयोगकर्ता फॉर्म भरता है (नाम, ईमेल, फोन, परिवार, पता, शिक्षा)
2. OTP भेजा और सत्यापित किया जाता है
3. POST /api/auth/register → उपयोगकर्ता बनाया जाता है
4. छात्र आईडी जनरेट की जाती है
5. JWT कुकी सेट + स्वागत ईमेल
```

---

## 2. JWT टोकन

### विशेषताएं:
- **एल्गोरिदम**: HMAC-SHA256 (Web Crypto API)
- **भंडारण**: HttpOnly Secure कुकी (क्लाइंट-साइड JS से अभिगम्य नहीं)
- **समाप्ति**: 
  - छात्र: 1.5 घंटे
  - एडमिन/शिक्षक: 2.5 घंटे
- **निष्क्रियता सीमा**: 1 घंटा (स्वचालित लॉगआउट)

### JWT पेलोड:
```typescript
{
  sub: user_id,
  role: "student" | "admin" | "teacher",
  session_id: string,
  iat: number,
  exp: number
}
```

### मुख्य फ़ंक्शन:
- `signJWT(payload, secret)` - टोकन हस्ताक्षर
- `verifyJWT(token, secret)` - टोकन सत्यापन

---

## 3. OTP प्रणाली

### डेटाबेस टेबल: `OTPs`

| फ़ील्ड | विवरण |
|--------|--------|
| `id` | अद्वितीय आईडी |
| `email` | ईमेल पता |
| `otp` | 6-अंकीय OTP |
| `used` | उपयोग किया गया (बूलियन) |
| `expires_at` | समाप्ति तिथि |
| `created_at` | निर्माण तिथि |

### OTP नियम:
- 6 अंकों का क्रिप्टोग्राफिक रूप से यादृच्छिक कोड
- दर सीमित: 1 OTP प्रति मिनट प्रति ईमेल
- समाप्ति: 10 मिनट (निर्धारित)
- उपयोग के बाद अमान्य

### API:
- `POST /api/auth/send-otp` - OTP भेजें
- `POST /api/auth/verify-otp` - OTP सत्यापित करें

---

## 4. सत्र प्रबंधन (Session Management)

### useSessionGuard (`hooks/useSessionGuard.tsx`)
क्लाइंट-साइड सत्र सुरक्षा:
- निष्क्रियता ट्रैकर (5 मिनट में पिंग)
- लॉगआउट से 2 मिनट पहले चेतावनी मोडल
- `SESSION_EXPIRED` / `INACTIVITY_LOGOUT` पर स्वचालित लॉगआउट

### नीतियां (`hooks/sessionGuardPolicy.ts`):
- `STUDENT_INACTIVITY_LIMIT_MS`: 12 घंटे (JWT से स्वतंत्र)
- `PRIVILEGED_INACTIVITY_LIMIT_MS`: 3 घंटे (एडमिन/शिक्षक)
- `WARNING_BEFORE_MS`: 2 मिनट
- `PING_INTERVAL_MS`: 5 मिनट

### API:
- `POST /api/auth/refresh-session` - सत्र ताज़ा करें (गतिविधि पिंग)
- `POST /api/auth/logout` - लॉगआउट (कुकी साफ़ + सत्र नष्ट)

---

## 5. मिडलवेयर (Middleware)

### Next.js Edge Middleware (`middleware.ts`)
- JWT सत्र सत्यापन (60s इन-मेमोरी कैश)
- अप्रमाणित उपयोगकर्ताओं को `/admin` और `/dashboard` से रीडायरेक्ट
- `jose` लाइब्रेरी का उपयोग

### Worker Middleware (`src/index.ts`)
- `requireAuth()` - JWT + सत्र आईडी सत्यापन
- `requireAdmin()` - एडमिन भूमिका + सत्र
- `requireAdminOrTeacher()` - एडमिन या शिक्षक भूमिका

---

## 6. एडमिन एक्शन OTP

खतरनाक एडमिन कार्यों के लिए अतिरिक्त OTP सुरक्षा:
- `handleAdminSendActionOTP()` - एक्शन OTP भेजें
- `verifyAdminActionOTP()` - एक्शन OTP सत्यापित करें

OTP-सुरक्षित कार्य:
- उपयोगकर्ता हटाना
- क्रेडिट प्रबंधन
- प्रमाणपत्र जारी करना
- एनरोलमेंट प्रबंधन

---

## 7. सुरक्षा विशेषताएं

- **HttpOnly कुकीज़** - XSS से सुरक्षा
- **रेट लिमिटिंग** - OTP स्पैम से सुरक्षा
- **टाइमिंग-सेफ तुलना** - साइड-चैनल अटैक से सुरक्षा
- **सत्र आईडी सत्यापन** - DB में सत्र मौजूद होना चाहिए
- **CORS सुरक्षा** - गतिशील ओरिजिन व्हाइटलिस्ट
- **ऐप सिग्नेचर** - HMAC अनुरोध हस्ताक्षर (Flutter ऐप्स)
